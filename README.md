# 🤖 ПедПульт — Бот-ассистент для учителей

Проект разработан в рамках хакатона «Идея Фикс» (направление «Арсенал мастера»).
Бот помогает учителям автоматизировать рутину, искать материалы, общаться и формировать отчёты.

## 📋 Требования
- Установленный [Docker](https://www.docker.com/)
- Или Python 3.10+ (для локального запуска без Docker)

## 🚀 Запуск через Docker (рекомендуется)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/pedpult-bot.git
   cd pedpult-bot
2. Соберите Docker-образ:
   ```bash
   docker build \-t pedpult-bot .
3. Запустите контейнер, передав токен бота:
   ```bash
   docker run -e BOT_TOKEN="ваш_токен_бота" pedpult-bot
## 💻 Запуск через командную строку (локально)

1. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/Mac
   # venv\Scripts\activate   # Для Windows
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
3. Запустите бота, передав токен в переменную окружения:
   ```bash
   export BOT_TOKEN="ваш_токен_бота"  # Linux/Mac
   # set BOT_TOKEN="ваш_токен_бота"   # Windows
   python main.py
## 🛠️ Функционал
-   Регистрация пользователя (ФИО, школа (техникум), предмет).
-   Главное меню с 4 модулями: Рутина, Поиск, Общение, Отчёты.
-   Просмотр профиля.
